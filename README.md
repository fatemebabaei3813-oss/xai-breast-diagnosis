# تشخیص بالینی تومور پستان — مدل قابل تفسیر

این پروژه یک **رابط کاربری هوشمند و قابل تفسیر** برای تشخیص اولیهٔ تومور پستان بر اساس ویژگی‌های مورفولوژیک سلولی (داده‌های سیتوپاتولوژی) ارائه می‌دهد.  
مدل با استفاده از قوانین ساده و شهودی (Rule-based)، احتمال بدخیمی را بر اساس ۶ فیچر بالینی کلیدی پیش‌بینی می‌کند و توضیحات پزشکیِ فارسی برای هر فیچر در اختیار کاربر قرار می‌دهد.

## 📌 نکتهٔ بسیار مهم

این فعالیت، **نمونه‌ای از به‌کارگیری یادگیری ماشین و ظرفیت بالای مدل‌های هوش مصنوعی** در حوزهٔ سلامت است.  
با این حال، **این ابزار جایگزین تشخیص پزشکی نیست** و تنها برای کمک به درک اولیهٔ رابطهٔ بین ویژگی‌های سلولی و وضعیت تومور طراحی شده است.  
برای استفادهٔ بالینی و تصمیم‌گیری درمانی، **حتماً باید نظر پاتولوژیست یا متخصص انکولوژی مربوطه اخذ شود**.
