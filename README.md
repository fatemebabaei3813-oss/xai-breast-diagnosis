‫# Breast Cancer Ruleset Classifier — نسخهٔ فارسی قابل تفسیر‬
‫‬
‫یک **دموی تعاملی** از یک مدل قاعده‌محور ساده برای تشخیص خوش‌خیم یا بدخیم بودن تومور پستان،  ‬
